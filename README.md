# STM32F103C8T6 开发知识库

面向 HAL 开发的中文技术参考，按硬件配置、运行机制和故障排查组织。器件为 64 KiB Flash、20 KiB SRAM、LQFP48 封装。

## 从这里开始

- [HAL 开发入口](知识库/HAL开发参考入口.md)：初始化、MSP、中断、DMA、时基与各外设接口。
- [完整目录](目录.md)：按主题查找正文、参数、接口和专题。
- [官方资料目录](来源/README.md)：手册、数据手册、应用笔记、勘误和固定版本源码。

## 主题正文

1. [器件与硬件设计](知识库/01_器件边界与硬件设计.md)：供电、引脚、启动、复位和晶振。
2. [时钟、复位与低功耗](知识库/02_时钟复位与低功耗.md)：时钟树、改频、唤醒、RTC 和故障切源。
3. [GPIO、中断与内核调试](知识库/03_GPIO中断与内核调试.md)：引脚配置、复用、中断路由、异常和调试。
4. [DMA 与缓冲区协作](知识库/04_DMA与缓冲区协作.md)：请求映射、启动与停止、缓冲区交接和吞吐量。
5. [ADC 采集与精度](知识库/05_ADC采集与精度.md)：采样窗口、触发、数据搬运、双 ADC 和误差预算。
6. [定时器、PWM 与同步](知识库/06_定时器PWM与同步.md)：计数、捕获、波形、同步、输出保护和 HAL 接口。
7. [USART 与串口数据流](知识库/07_USART与串口数据流.md)：帧格式、接收事件、DMA、驱动状态和错误恢复。
