## 图形含义与使用条件

- 图8是输入信号与采样配对的概念示意，不是电压、电流传感器或功率测量电路。原图单相公式确实漏写第二因子的电流符号；正文按§2.1.2给出的电压乘电流关系说明，并保留量纲、码值换算和三相逐对采样的条件。
- 图12保留原CH10、CH11、CH14、CH15等系列标签，不增加本封装的可用输入。规则与注入组的配置条件须结合相邻说明和RM0008；图块长度不用于反推精确时长。
- 图14是电池、逆变和负载的功能框图。它只说明规则交错监测电池、注入同时测量负载电压和电流的分工，不提供完整功率级、信号调理或保护电路。

本轮已目视核对pp9–10、14–15的完整源页、相关正文及这三幅最终裁图。其余AN3116原图未在本批收录，源页与裁图核对不等于知识库所有页面、模式或固件已完成验证。三图分别位于[模式应用关系](../../../参数/ADC/模式应用关系.md)的同步功率、规则与注入同时、UPS小节旁。
