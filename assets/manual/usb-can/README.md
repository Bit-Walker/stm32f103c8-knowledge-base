## 完整性与适用边界

- Figure 221 保留图号、完整标题、全部描述项地址/计数字段、指向箭头、缓冲区名称、单/双缓冲标识和底部图标识。没有编号脚注。相邻 p627 的 BTABLE 对齐、每项四个 16 位字及 PMA 共用关系，由正文布局说明承接；图中间隙和块大小不表示可直接使用的容量配置。
- Figure 221 的 EP2/EP3 是双缓冲示例，不能据此声称本页已说明其完整所有权和操作流程。p628 图后关于硬件包缓冲边界的文字，不替代应用 SRAM 的对象容量检查，也不覆盖 ES096 接收计数/CRC 存储勘误。
- Figure 228 保留图号、完整标题、全部状态与 RQCP/TXOK/TME 字段、优先级箭头、ABRQ 路径，以及失败路径的 NART 上横线。没有编号脚注。p661 的发送中取消竞态与非自动重发说明在正文图旁承接，不能只凭图判定请求已撤销。
- Figure 228 是硬件状态图，不证明固定 HAL 返回时已经成功发送，也不证明接收应用完成业务。裁图完整保留 Figure 228，不含后续正文。

本记录只覆盖上述两幅原图及列明的相邻条件，不代表 USB/CAN 全章收录、完整协议栈验证或实板认证。技术来源范围见 [RM0008 USB](../../../来源/RM0008.md#src-rm0008-r21-usb-memory-endpoint) 与 [RM0008 CAN](../../../来源/RM0008.md#src-rm0008-r21-can-mailbox-fifo)。
