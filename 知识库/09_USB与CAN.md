# USB 与 CAN

[返回目录](../目录.md) · [HAL 开发参考](HAL开发参考入口.md)

STM32F103C8T6 的 USB 与 CAN 共享 512 字节专用 SRAM，不能同时工作。先按[硬件资源限制](01_器件边界与硬件设计.md#12-引脚图与复用限制)选择功能，再核对时钟、引脚及缓冲管理；将 CAN 移到 PB8/PB9 不会解除内部共享限制。[RM0008 共享资源](../来源/RM0008.md#src-rm0008-r21-resource-conflict)

## 按当前问题查阅

- [USB PMA 配置与连接控制](../参数/USB/PMA配置与连接控制.md)：句柄关联、单缓冲配置、端点开启与板级连接钩子。
- [USB 容量与端点副作用](../参数/USB/容量与端点副作用.md)：PMA实际容量、应用缓冲访问、接收计数、端点写入语义及相关勘误。
- [CAN 邮箱 FIFO 与错误边界](../参数/CAN/邮箱FIFO与错误边界.md)：提交与完成、取消竞态、8字节访问、接收释放、溢出及bus-off恢复。

USB 的 HSE晶体、PLL与48MHz条件见[时钟树](02_时钟复位与低功耗.md#11-频率与分频)；USB PA11/PA12见[LQFP48固定功能](../参数/LQFP48引脚电气类别.md)，CAN PA11/PA12与PB8/PB9见[引脚映射](../参数/引脚复用与AFIO.md#通信定时器映射)。IRQ19/20的共享关系见[C8外部向量表](../参数/C8外部向量表.md)，不能由向量名称推断两外设可并发。

两篇使用边界页绑定 STM32CubeF1 v1.8.6 配套 HAL v1.1.10；现有初始化页保留其独立固定版本。旧版与新版的差异只按列明路径解释，不由相同函数名推定所有版本一致。

本主题未提供完整USB协议栈或CAN应用工程，也没有板端枚举、收发或故障注入验证。当前范围与尚未展开内容见[已知限制](../已知限制.md#usb-与-can-恢复范围)。
