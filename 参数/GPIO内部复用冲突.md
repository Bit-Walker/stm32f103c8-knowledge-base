# GPIO内部复用冲突

依据ES096 Rev15 §2.3.1–§2.3.10，印刷页与PDF文件页pp10–13。下表为全部十条，保留输入、输出、时钟、映射及无规避条件。覆盖本主题GPIO部分。

| 原条款/页 | 同时成立的条件 | 后果 | 原厂规避及边界 |
|---|---|---|---|
| §2.3.1 p10 | USART1有时钟；CAN无时钟；PA12为复用输出 | 即使不用CAN_TX，内部CAN_TX默认1，USART1_RTS不可用 | 使用USART1_RTS时：若也用CAN，CAN移到另一I/O配置；若不用CAN，CAN_REMAP=01未用配置。01仅是该条明确规避，不是CAN正常映射 |
| §2.3.2 pp10–11 | SPI1与USART2均有时钟；PA4为复用输出；SPI1从机 | USART2同步CK不能使用 | 无规避 |
| §2.3.3 p11 | SPI1与USART2均有时钟；PA4为复用输出；SPI1主机且NSS软件管理 | USART2_CK不输出，不能用于同步模式 | 要输出USART2_CK，置SPI1_CR2.SSOE，使SPI1 NSS配置为输出；原条款只明确要求SSOE置位，不额外推定SSM配置步骤 |
| §2.3.4 p11 | SPI2与USART3均有时钟；PB12为复用输出；SPI2从机 | USART3同步CK不能使用 | 无规避 |
| §2.3.5 p11 | SPI2与USART3均有时钟；PB12为复用输出；SPI2主机且NSS软件管理 | USART3_CK不输出，不能用于同步模式 | 要输出USART3_CK，置SPI2_CR2.SSOE，使SPI2 NSS配置为输出 |
| §2.3.6 pp11–12 | I2C2与SPI2同时有时钟，或I2C2与USART3同时有时钟；PB12为复用输出 | 即使未用SMBA，I2C2_SMBA仍与SPI2_NSS输出或USART3_CK冲突；该AF输出且I2C2有时钟时PB12默认1 | I2C2_SMBA作为输出：SPI2必须主机且NSS软件管理；I2C2_SMBA作为输入：SPI2可主/从机，但NSS须软件管理。I2C2使用中，SPI2不得用其他配置；USART3不得用同步模式 |
| §2.3.7 p12 | I2C1与SPI1均有时钟；SPI1已重映射；PB5为复用输出；条款限定重映射SPI1主机 | SPI1_MOSI与I2C1_SMBA内部冲突，即使SMBA未用 | 不并用I2C1和重映射SPI1主机；原workaround进一步写明使用重映射SPI1时关闭I2C1时钟。不得只靠GPIO重配消除 |
| §2.3.8 p12 | I2C1与TIM3均有时钟；PB5为复用输出（对应重映射TIM3_CH2） | I2C1_SMBA即使未使用仍冲突，PB5默认1；TIM3_CH2输出不可用 | TIM3_CH2仅可使用输入模式 |
| §2.3.9 pp12–13 | USART仅接收，USARTx_CR1.TE=0；该USARTx_TX脚共享另一复用输出 | 即使未使用TX，内部TX输出为1，不能输出其他AF | 不把该USARTx_TX对应引脚配置为AF输出；原workaround称仅可用输入模式，并保持TE=0。不能缩略成“TX未用所以可任意复用” |
| §2.3.10 p13 | USART1及TIM1均有时钟；PA9为复用输出；正文写TIM1_CH2 PWM enabled without output | USART1 Tx(PA9)发送异常字符 | 原workaround要求用TIM1_REMAP把TIM1_CH2移到其他I/O；但C8的部分映射仍PA9，全映射PE11不引出，不能提供可用C8重映射方案。标题with output与正文without output不一致，保留原差异，不自改触发条件 |

修订适用性：Table3 pp2–3逐行列§2.3.1–9，列顺序A/B/Z/1/Y/2/3/X。§2.3.2和§2.3.4各列N，其余七条各列A；A表示限制存在且有规避，N表示限制存在且无规避，不是“已修复”。§2.3.10未列于Table3，不能补成任何修订状态。此处只摘GPIO九行，不替代其余ES096矩阵。

C8裁剪依据：RM0008 Rev21 §9.3.7 Table46 p179（TIM1_CH2默认和部分映射PA9、全映射PE11）；DS5319 Rev20 §3 Table5 pp28–33（LQFP48不引出PE11）。CAN映射的特殊01规避保留ES096优先，普通CAN映射表仍将01标未用。
