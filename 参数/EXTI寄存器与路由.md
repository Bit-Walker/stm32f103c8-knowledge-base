# EXTI 寄存器与路由

EXTI（外部中断与事件控制器）将输入边沿或软件请求送往中断路径、事件路径。配置时需要分别确定输入来源、触发边沿、路径掩码和中断入口。

有效线路为 EXTI0～18。寄存器采用 32 位访问，位 31:19 为保留位。以下依据 RM0008 Rev21 §10.2～§10.3。

## 1 输入来源与路由

| EXTI 线路 | 输入来源 | 选择方式 |
|---|---|---|
| 0～15 | PA0～15、PB0～15；PC13～15 对应线路 13～15 | 每条线选择一个同号 GPIO |
| 16 | PVD | 固定内部连接 |
| 17 | RTC Alarm | 固定内部连接 |
| 18 | USB Wakeup | 固定内部连接 |

例如 PA0 和 PB0 共用 EXTI0 的来源选择，不能同时作为两个独立的 EXTI0 输入。配置来源前先开启 AFIO 时钟。PD0/PD1 的 OSC 重映射不提供 EXTI 路径。

来源：[RM0008 §10.2.5、Figure21 及 AFIO_EXTICR 定义](../来源/RM0008.md#src-rm0008-r21-exti-route)，p210、pp191～192；[PD0/PD1 条件](../来源/RM0008.md#src-rm0008-r21-gpio-pd01)，p175。

## 2 中断与事件的数据通路

![RM0008 Rev21 Figure20，p207：EXTI 中断与事件框图](../assets/manual/rm0008-r21/p207-gpio-exti.png)

输入线先进入边沿检测器，RTSR 和 FTSR 分别控制上升沿、下降沿检测。检测请求与软件请求汇合后分为两条路径：

- 中断路径：IMR 门控 → PR 挂起寄存器 → NVIC。
- 事件路径：EMR 门控 → 脉冲发生器。

IMR 和 EMR 可以独立配置。只启用事件与同时启用中断、事件具有不同的行为；仅在 NVIC 禁止中断也不等同于关闭 IMR。图中的中断锁存位于 IMR 之后，不能假定 IMR 关闭期间的所有边沿仍会累计到 PR。

原图取自 RM0008 Rev21 Figure20，p207，保留原有连线。路径解释依据 [§10.2.3～§10.2.4](../来源/RM0008.md#src-rm0008-r21-exti-route)。原图中的线路数量不代表寄存器访问宽度。

## 3 寄存器与复位值

下表偏移均相对于 EXTI 寄存器基址；有效控制位为 18:0。rw 表示可读写，rc_w1 表示可读、写 1 清除。

| 寄存器 | 全称 | 偏移 | 访问属性 |
|---|---|---:|---|
| EXTI_IMR | Interrupt mask register，中断屏蔽寄存器 | 0x00 | rw |
| EXTI_EMR | Event mask register，事件屏蔽寄存器 | 0x04 | rw |
| EXTI_RTSR | Rising trigger selection register，上升沿触发选择寄存器 | 0x08 | rw |
| EXTI_FTSR | Falling trigger selection register，下降沿触发选择寄存器 | 0x0C | rw |
| EXTI_SWIER | Software interrupt event register，软件中断事件寄存器 | 0x10 | rw |
| EXTI_PR | Pending register，挂起寄存器 | 0x14 | rc_w1 |

IMR、EMR、RTSR、FTSR、SWIER 的复位值均为 0。

**PR 复位值存在原文差异。** §10.3.6 p213 的详细定义写 undefined，§10.3.7 p214 的 Table64 汇总表列为全 0。初始化时显式清除目标线路的挂起位，不依赖其中某一处描述推定初始状态。

来源：[RM0008 §10.3～§10.3.7](../来源/RM0008.md#src-rm0008-r21-exti-reg)，pp211～214。

## 4 控制位与访问副作用

| 寄存器 | 对应位的作用 |
|---|---|
| IMR | 0 屏蔽中断请求；1 放行 |
| EMR | 0 屏蔽事件请求；1 放行 |
| RTSR | 1 启用上升沿触发，同时影响中断与事件 |
| FTSR | 1 启用下降沿触发，同时影响中断与事件 |
| SWIER | IMR 放行时，对应位从 0 写为 1 会置位 PR 并产生中断请求；通过向 PR 写 1 清除对应 SWIER |
| PR | 读到 1 表示已发生请求；写 1 清除对应挂起位 |

### 4.1 边沿选择的写入窗口

同一线路可以同时启用 RTSR 和 FTSR，使上升沿、下降沿都能触发。

写 RTSR 期间到达的上升沿、写 FTSR 期间到达的下降沿不会置位 PR。动态切换检测边沿可能丢失这个窗口内的请求；原文还要求输入不得产生毛刺。依据为 §10.3.3～§10.3.4 p212 的两条注释。

### 4.2 清除挂起位

清除 PR 时直接写目标掩码。对 PR 进行读改写，会把读到为 1 且写回为 1 的其他线路一并清除。

SWIER 的触发条件是对应位从 0 变为 1；清除 PR 同时清除对应 SWIER。因此重复发出软件请求前，应完成相应挂起清除。具体请求能否进入处理函数，还取决于 IMR、NVIC 和异常屏蔽配置。

以上控制位及访问行为见 [RM0008 §10.3.1～§10.3.6](../来源/RM0008.md#src-rm0008-r21-exti-reg)。

## 5 共享中断入口与低功耗

| 共享中断入口 | EXTI 线路 | IRQ 编号 |
|---|---|---:|
| EXTI9_5 | 5～9 | 23 |
| EXTI15_10 | 10～15 | 40 |

共享 ISR 应识别全部可能来源，不能仅处理其中一条线路后就认定请求已全部撤销。这是由共享入口关系导出的处理要求。完整 IRQ 编号见[外部向量表](C8外部向量表.md)，原厂依据为 [RM0008 Table63](../来源/RM0008.md#src-rm0008-r21-exti-vector)，pp205～206。

WFE 的两种源配置、SEVONPEND 和清挂起关系见 RM0008 §10.2.3 p208。PVD、USB Wakeup 的适用限制及 WFE 竞态还须结合[时钟复位与低功耗](../知识库/02_时钟复位与低功耗.md)中的勘误说明；适用范围不得扩大到未列明的内核修订。

使用 HAL 时，继续查阅[GPIO 与 EXTI 调用边界](HAL_GPIO与EXTI调用边界.md)，核对 GPIO、EXTI 与 NVIC 初始化各自承担的步骤。
