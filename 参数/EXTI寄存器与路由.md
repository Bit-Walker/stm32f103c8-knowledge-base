# EXTI寄存器与路由

依据RM0008 Rev21 §10.2–§10.3 pp207–214；访问宽度32位（§10.3 p211）。C8仅实现EXTI0–18，下列寄存器bit19不适用，bits31:19按保留位处理，不能将互联型20线描述照搬。

| 寄存器 | 偏移 | 复位 | C8位18:0语义 | 原位置 |
|---|---|---|---|---|
| EXTI_IMR | 0x00 | 0 | rw，0屏蔽中断请求，1不屏蔽 | §10.3.1 p211 |
| EXTI_EMR | 0x04 | 0 | rw，0屏蔽事件请求，1不屏蔽 | §10.3.2 p211 |
| EXTI_RTSR | 0x08 | 0 | rw，1启用上升沿触发；同时影响中断和事件 | §10.3.3 p212 |
| EXTI_FTSR | 0x0C | 0 | rw，1启用下降沿触发；同时影响中断和事件 | §10.3.4 p212 |
| EXTI_SWIER | 0x10 | 0 | rw；IMR使能时对应位从0写1置PR并产生中断请求；通过对PR写1清除对应SWIER | §10.3.5 p213 |
| EXTI_PR | 0x14 | 详细定义undefined；Table64全0 | rc_w1，读1表示请求发生；写1清对应位 | §10.3.6 p213；§10.3.7 p214 |

RTSR/FTSR可同线同时使能，两种边沿均触发。写RTSR期间到达的上升沿、写FTSR期间到达的下降沿不会置PR；输入不得产生毛刺（两条Note p212）。寄存器读改写PR会清除所有读到为1且写回1的位，因此清除动作直接写目标掩码，不把其他位状态回写为1。

Figure20 p207：Input Line→Edge detect；RTSR/FTSR控制检测；软件请求与检测请求汇合后分为两路。中断路先经IMR门控，再进PR，到NVIC；事件路经EMR门控，再由Pulse generator产生事件。故仅事件模式与同时中断+事件不同；只关NVIC也与关IMR不同。此图及§10.2.3–4 p208支持这些关系，不把PR字段简写“边沿置位”扩展成IMR关闭时仍累计全部边沿。

Figure21 p210及§9.4.3–6 pp191–192：EXTIn只选择一个同号GPIO端口输入；AFIO时钟先开。C8的PA0–15、PB0–15、PC13–15才有相应GPIO外部路径，PD0/PD1按§9.3.2 p175不随OSC重映射获得EXTI。内部EXTI16=PVD、17=RTC Alarm、18=USB Wakeup。图中112 GPIO及EXTI19不是C8资源数量。

EXTI9_5和EXTI15_10分别共享IRQ23、40，原厂Table63 pp205–206。共享ISR应识别全部可能来源，是共享入口推导的处理约束；本表不替代NVIC寄存器章节。WFE两种源配置、SEVONPEND和清挂起关系见§10.2.3 p208；C8 PVD/USB及WFE竞态的适用勘误继续依赖时钟/低功耗主题，其适用范围不能扩展到未列明的内核修订。
