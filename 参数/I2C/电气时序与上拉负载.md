# I²C 电气时序、上拉与负载

先检查供时和总线负载，再核对 SCL 高低电平、SDA 建立保持与起停间隔。下表按这些检查步骤重组 DS5319 Rev20 Table41–42，适用于 I2C1/2；不把 HAL 函数执行时间当成总线时序。

## 1 适用条件与保证类型

| 检查项 | 条件或边界 | 来源 |
|---|---|---|
| 供电 | VDD=2～3.6 V；VDD 为器件主电源，不与总线上拉电源 VDD_I2C 混为一项 | Table9 p38；Figure32 p69 |
| I2C 供时 | fPCLK1 是 APB1 时钟频率，上限36 MHz；标准模式至少2 MHz，快速模式至少4 MHz | Table9；Table41注2 |
| 400 kHz 条件 | Table41注2另要求 fPCLK1 为10 MHz的整数倍；与第4节表42示例的差异须单独保留 | Table41注2 |
| 表41保证类型 | 全表均为设计规定，未经生产测试；不能改称逐片实测保证 | Table41注1 |
| GPIO结构 | SDA/SCL 不是“真正”的开漏：配置为开漏时，接到VDD的PMOS被禁用但仍存在 | §5.3.16 p68 |

通用供电、温度与功耗条件（Table9），以及输入阈值、注入电流和GPIO驱动约束见[硬件电气参数](../01_硬件电气参数.md)；引脚与重映射见[引脚复用与AFIO](../引脚复用与AFIO.md)。

以下“未列”表示原表以短横线表示没有列出该边界，不表示0、无穷大或无条件允许；原表空白另作明确标识。各表的数值均来自[Table41 p68](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf#page=68)。

## 2 先核对上拉、负载和边沿

| 符号与检查对象 | 标准模式 Min / Max | 快速模式 Min / Max | 单位 |
|---|---|---|---|
| Cb：每根总线的电容负载 | 未列 / 400 | 未列 / 400 | pF |
| tr(SDA)、tr(SCL)：SDA与SCL上升时间 | 未列 / 1000 | 未列 / 300 | ns |
| tf(SDA)、tf(SCL)：SDA与SCL下降时间 | 未列 / 300 | 未列 / 300 | ns |
| tSP：模拟滤波器抑制的尖峰脉宽 | 0 / 50 | 0 / 50 | ns |

表41注4的原意另行保留：模拟滤波器所滤除尖峰的最小宽度高于 tSP(max)。它与表内 tSP 定义的关系不够直观；本文不据此推导“≤50 ns必定被滤除”或“>50 ns必定不滤除”等额外结论。

测量阈值按[Figure32 p69](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf#page=69)的0.3 VDD与0.7 VDD。原图中 Rp 是外部上拉电阻，Rs 是串联保护电阻，VDD_I2C 是I²C总线电源。图与表均未在这里给出适用于任意负载的统一Rp推荐值；表42的4.7 kΩ只是该组条件，不能替代每根线的电容和边沿检查。

## 3 再核对数据与起停时序

### 3.1 SCL高低电平与SDA有效窗口

|---|---|---|---|
| tw(SCLL)：SCL低电平时间 | 4.7 / 未列 | 1.3 / 未列 | µs |
| tw(SCLH)：SCL高电平时间 | 4.0 / 未列 | 0.6 / 原格空白 | µs |
| tsu(SDA)：SDA建立时间 | 250 / 未列 | 100 / 未列 | ns |
| th(SDA)：SDA数据保持时间 | 未列 / 3450 | 未列 / 900 | ns |

表41注3：接口不延长SCL低电平期间时，必须满足上述最大数据保持时间。不要删去这项条件，也不要给未列出的最小保持时间补0。

## 4 使用36 MHz配置示例时保留条件

[Table42 p69](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf#page=69)固定条件为 fPCLK1=36 MHz、VDD_I2C=3.3 V、Rp=4.7 kΩ。下表按频率从低到高排列；fSCL是SCL总线时钟频率，I2C_CCR列是原表给出的寄存器值，不是只有CCR低位的十进制计数。

| fSCL（kHz） | I2C_CCR | 表42注2的频率容差 |
|---:|---|---|
| 20 | 0x0384 | ±2% |
| 50 | 0x0168 | ±2% |
| 100 | 0x00B4 | ±2% |
| 200 | 0x803C | 约200 kHz范围为±5% |
| 300 | 0x8028 | ±2% |
| 400 | 0x801E | ±2%；另见下述来源差异 |

表42注1定义Rp为外部上拉电阻、fSCL为I²C速度；注2说明约200 kHz的实现速度容差为±5%，其他频率范围为±2%，这些变化取决于应用外部元件的精度。原表没有界定“约200 kHz”的精确区间，也没有单独注明表42的生产测试或特性评估保证类型；不把表41注1自动扩大为表42的保证声明。

**400 kHz的两处描述存在未解决差异。** 表42确实给出36 MHz条件下0x801E对应400 kHz，而表41注2要求达到400 kHz时PCLK1为10 MHz的整数倍。36 MHz不满足后一项，不能用这个示例取消注2，也不能擅自把36 MHz改成其他频率。本页保存两处原文事实；使用这个边界点前需进一步取得厂商澄清并核查实际系统时序。本页没有新增官方勘误认定或板级验证结论。
