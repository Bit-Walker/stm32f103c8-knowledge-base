# 硅修订矩阵

本页保留修订状态与Table4分类，未在本主题重新核查所有外设规避正文。

## 1 适用器件、硅标记与状态解释

STM32F103C8T6 属于本勘误覆盖的中容量 STM32F103x8/B。原件还覆盖 F101x8/B、F102x8/B，以及订货号中不带字母 A 的 32 KB Flash 器件；不能把本表推广至其他密度或其他系列。

| 封装硅修订标记 | DBGMCU_IDCODE.REV_ID | 识别注意 |
|---|---|---|
| A | 0x0000 | 不可仅凭应用读回 0 判断 A |
| B | 0x2000 | 与 Z 同属旧优化序列限制范围 |
| Z | 0x2001 | 与 B 同属旧优化序列限制范围 |
| Y、X、1、2、3 | 0x2003 | 一个 REV_ID 无法区分这五种封装标记 |

REV_ID 是 DBGMCU_IDCODE 的高 16 位字段。原件的 `REV_ID[15:0]` 是该字段内部编号，不表示整个 IDCODE 的低 16 位。由于 §2.2.2，用户程序读取 DBGMCU_IDCODE/CR 返回 0；应由调试器与封装标记共同识别，不能写一段裸机读 ID 的代码来可靠选取全部规避路径。

状态：A＝限制存在且有规避；N＝限制存在且无规避；P＝只有部分规避；`—`＝不存在。P 可能仅降低发生率/后果，或仅覆盖部分实例、模式。即使标 A，措施也可能限制系统设计，不能理解成外设无条件正确。

**原件矩阵的边界与矛盾：**

- §2.3.10 在正文与修订记录存在，却未出现在 Table 3；没有依据补成“所有版本 A”或断言某修订已修复。按正文落实规避，版本精确豁免须取得 ST 确认。
- §2.4.2 与 §2.6.2 属于 Table 4 的文档勘误，不分硅修订。它们分别要求 DMA 寄存器 32 位访问、触发目标时钟先就绪。
- §2.2.9 矩阵包含 A/B/Z，正文仅点名 B/Z，正文声明 Y/1 不受影响；本参考保留差异，不擅自把 A 从适用范围删除。
- §2.12.3 矩阵写 N，正文“忽略缓冲区 CRC16”是应用处置，不代表能修正硬件写入值。
