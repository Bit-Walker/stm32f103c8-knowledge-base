# 定时器寄存器与配置参数

相同字段表在TIM1与TIM2～4之间合并，独有寄存器明确分开。本文件保留参数表并记录实例限制；完整位字段及脚注仍以固定版原手册为准，本表核查范围限所列条目与条件。

来源基线：[RM0008 Rev21 TIM1寄存器pp338–364](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=338)、[TIM2～4寄存器pp404起](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=404)。配套：[时基与更新](计数时基与更新.md)、[输出安全](输出级与保护.md)、[LL编码器符号](LL辅助宏.md#编码器-x2-模式的文档符号冲突)。

## 寄存器地图与实例差异

TIM1～TIM4 的公共寄存器：

|---|---|---|
| 0x00 | CR1 | 0 |
| 0x04 | CR2 | 0 |
| 0x08 | SMCR | 0 |
| 0x0C | DIER | 0 |
| 0x10 | SR | 0 |
| 0x14 | EGR | 0 |
| 0x18 | CCMR1 | 0 |
| 0x1C | CCMR2 | 0 |
| 0x20 | CCER | 0 |
| 0x24 | CNT | 0 |
| 0x28 | PSC | 0 |
| 0x2C | ARR | 0xFFFF |
| 0x34 | CCR1 | 0 |
| 0x38 | CCR2 | 0 |
| 0x3C | CCR3 | 0 |
| 0x40 | CCR4 | 0 |
| 0x48 | DCR | 0 |

| 偏移 | 寄存器 | 复位值 |
|---|---|---|
| 0x30 | RCR | 0 |
| 0x44 | BDTR | 0 |


32位寄存器CPU写访问用字，其他寄存器可用半字或字；读访问允许字节、半字或字。DMAR为32位间接窗口；RM的DMA burst半字搬运示例属于DMA路径，不据此改写CPU访问规则。保留位维持复位值。

## 编码器边沿与方向

|触发边沿|另一信号高|另一信号低|
|---|---|---|
|TI1 上升|向下|向上|
|TI1 下降|向上|向下|
|TI2 上升|向上|向下|
|TI2 下降|向下|向上|

相位关系按滤波和极性选择后的TI1FP1、TI2FP2解释，前提是两路不同时跳变。上表描述被所选编码器模式计数的边沿；未选通的那一路边沿不增加或减少CNT。

|SMS|计数边沿|另一输入的作用|
|---|---|---|
|001|TI2FP2上升、下降沿|TI1FP1电平参与方向判定；TI1单独跳变不计数|
|010|TI1FP1上升、下降沿|TI2FP2电平参与方向判定；TI2单独跳变不计数|
|011|TI1FP1与TI2FP2两路上升、下降沿|另一信号的电平决定各边沿方向|

DIR由硬件根据任一路跳变计算，包括当前模式未用于计数的输入；PSC仍参与计数路径。两路同时跳变不在原表保证范围。库的X2模式符号与注释区别见[LL辅助宏](LL辅助宏.md#编码器-x2-模式的文档符号冲突)。

来源：[RM0008 Rev21 §14.3.16、表81，pp329–330](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=329)。

## CR1计数控制

|位|字段|全部编码/语义|
|---|---|---|
|9:8|CKD|00：tDTS=tCK_INT；01：2×tCK_INT；10：4×tCK_INT；11 保留|
|7|ARPE|0 ARR 不缓冲；1 ARR 预装载在 UEV 生效|
|6:5|CMS|00 边沿对齐；01 中心对齐、仅下数设置输出比较标志；10 中心对齐、仅上数设置；11 上下均设置|
|4|DIR|0 上数；1 下数；中心对齐或编码器模式只读，由硬件管理|
|3|OPM|0 更新后继续；1 下次 UEV 清 CEN、停止|
|2|URS|0 溢出/下溢、UG、从控制器更新均可请求更新中断/DMA；1 只有溢出/下溢可请求|
|1|UDIS|0 允许 UEV 及影子装载；1 禁止 UEV、影子保持；UG/从复位仍初始化 CNT 和预分频计数|
|0|CEN|0 停止；1 允许计数；外部时钟、门控、编码器需先由软件置 1；触发模式可自动置 1|

共享于TIM1～4。CEN=1时不得由边沿切入中心对齐；UG/UDIS/URS关系详见时基文档。

## CR2的MMS触发输出

|MMS[6:4]|TRGO 来源|
|---|---|
|000|复位：EGR.UG；从模式复位产生的 TRGO 相对实际复位有延迟|
|001|使能：CNT_EN；外部触发控制的使能传播可能有延迟，MSM 用于主从对齐|
|010|更新：UEV，可作下一级预分频时钟|
|011|比较脉冲：每次捕获/比较将置 CC1IF 时输出正脉冲，即使 CC1IF 原已为 1|
|100|OC1REF|
|101|OC2REF|
|110|OC3REF|
|111|OC4REF|

这张表仅描述共享MMS字段。TIM2～4的CR2[15:8]及[2:0]保留，不存在TIM1的OIS/CCPC/CCUS。TI1S在bit7，CCDS在bit3。CCDS=0时CCx DMA请求由对应CCx事件产生，CCDS=1时改由更新事件产生；该选择不改变DMA1物理通道映射，也不改变CPAR外设地址。它是实例级共享位，影响已允许的CCx DMA请求，不能当作某一路通道私有配置。依据：RM0008 Rev21 CR2，TIM1 p341、TIM2～4 p406。

## SMCR时钟与从模式

|位|字段|全部编码/语义|
|---|---|---|
|15|ETP|0 ETR 不反相，高电平/上升沿有效；1 反相，低电平/下降沿有效|
|14|ECE|0 禁止外部时钟模式 2；1 ETRF 有效沿作计数时钟|
|13:12|ETPS|00 不分频；01 ÷2；10 ÷4；11 ÷8；分频后 ETRP≤fTIM/4|
|11:8|ETF|ETR 数字滤波，全部 16 档见下表|
|7|MSM|0 无协调延迟；1 延迟本级 TRGI 动作以与 TRGO 下级同步|
|6:4|TS|000 ITR0；001 ITR1；010 ITR2；011 ITR3；100 TI1F_ED；101 TI1FP1；110 TI2FP2；111 ETRF|
|2:0|SMS|000 禁从模式；001 编码器 TI2 计数；010 编码器 TI1 计数；011 编码器双输入计数；100 复位；101 门控；110 触发启动；111 外部时钟模式 1|

ECE不能与编码器模式同用；ECE配合复位/门控/触发时TS不可为111。TS=100双边沿检测不适用于门控。TS字段仅在未被使用时修改，以避免切换时错误边沿检测（RM0008 Rev21 p343；SMS=000是原文示例）；若TIM1仍通过CCUS消费TRGI产生COM，也须隔离该路径。内部时钟可以配合SMS=100/101/110，不能把SMS=000当作其通用必要条件。

|0000|fDTS，无滤波|—|
|0001|fCK_INT|2|

|0011|fCK_INT|8|
|0100|fDTS/2|6|
|0101|fDTS/2|8|
|0110|fDTS/4|6|

N为确认新电平所需连续样本数，无量纲；fCK_INT为定时器内部时钟，fDTS由CKD得到，单位均Hz。0001～0011使用fCK_INT，不能把这三档一律写成fDTS。0000为无滤波编码。RM0008 p314示例称0011按fDTS采样，与p351字段表的fCK_INT存在措辞差异；只有CKD=00时二者相等。详见[捕获时钟核对](输入捕获与滤波.md#滤波示例与字段表的来源差异)。

## DIER共享请求位

|位|字段|事件|
|---|---|---|
|14|TDE|触发 DMA|
|12|CC4DE|通道 4 捕获比较 DMA，时机由 CCDS 选择|
|11|CC3DE|通道 3 捕获比较 DMA，时机由 CCDS 选择|
|10|CC2DE|通道 2 捕获比较 DMA，时机由 CCDS 选择|
|9|CC1DE|通道 1 捕获比较 DMA，时机由 CCDS 选择|
|8|UDE|更新 DMA|
|6|TIE|触发中断|
|4|CC4IE|通道 4 捕获比较中断|
|3|CC3IE|通道 3 捕获比较中断|
|2|CC2IE|通道 2 捕获比较中断|
|1|CC1IE|通道 1 捕获比较中断|

TIM1另有bit13 COMDE、bit7 BIE、bit5 COMIE。TIM2～4这些位保留。没有独立BDE刹车DMA位；RM正文出现BDE不能替代寄存器定义。

## CCMR共享位布局

CCMR1 管理 CH1、CH2；CCMR2 管理 CH3、CH4。同一位段的含义由 CCxS 选择的输入/输出模式决定。

### 输出模式字段

| 寄存器 / 通道 | CCxS | OCxFE | OCxPE | OCxM | OCxCE |
|---|---|---|---|---|---|
| CCMR1 / CH1 | 1:0 | 2 | 3 | 6:4 | 7 |
| CCMR1 / CH2 | 9:8 | 10 | 11 | 14:12 | 15 |
| CCMR2 / CH3 | 1:0 | 2 | 3 | 6:4 | 7 |
| CCMR2 / CH4 | 9:8 | 10 | 11 | 14:12 | 15 |

### 输入模式字段

| 寄存器 / 通道 | CCxS | ICxPSC | ICxF |
|---|---|---|---|
| CCMR1 / CH1 | 1:0 | 3:2 | 7:4 |
| CCMR1 / CH2 | 9:8 | 11:10 | 15:12 |
| CCMR2 / CH3 | 1:0 | 3:2 | 7:4 |
| CCMR2 / CH4 | 9:8 | 11:10 | 15:12 |

## CCxS输入输出映射

|通道|00|01|10|11|
|---|---|---|---|---|
|1|输出|IC1←TI1|IC1←TI2|IC1←TRC|
|2|输出|IC2←TI2|IC2←TI1|IC2←TRC|
|3|输出|IC3←TI3|IC3←TI4|IC3←TRC|
|4|输出|IC4←TI4|IC4←TI3|IC4←TRC|

CCxS只在CCxE=0时可写。TRC来自TS选择的触发路径，不是独立封装引脚。CCxS字段说明使用“internal trigger input”措辞，但不能据此把TRC限定为ITR0～ITR3：RM0008 p332的Hall示例及固定HAL/LL实现均同时选择CC1S=11与TS=100（TI1F_ED）。该例详见[Hall与从模式](同步控制与Hall.md#hall接口的触发与捕获)。

## 共享计数与比较寄存器

|寄存器|偏移|复位|字段与访问|
|---|---|---|---|
|CNT|0x24|0x0000|CNT[15:0]，rw，当前计数值|
|PSC|0x28|0x0000|PSC[15:0]，rw，实际分频 PSC+1，UEV 装入活动预分频器|
|ARR|0x2C|0xFFFF|ARR[15:0]，rw，自动重装值，ARPE 决定生效时机；0 阻塞计数|
|CCR1|0x34|0x0000|CCR1[15:0]，输出 rw、输入 r|
|CCR2|0x38|0x0000|CCR2[15:0]，输出 rw、输入 r|
|CCR3|0x3C|0x0000|CCR3[15:0]，输出 rw、输入 r|
|CCR4|0x40|0x0000|CCR4[15:0]，输出 rw、输入 r|

输出模式CCR可写且受预装载控制；输入模式CCR只读，读取清对应CCxIF，捕获竞争例外见ES096。TIM1独有0x30 RCR，其低8位有效；TIM2～4该地址保留。

## TIM1 BDTR

|位|字段|语义|
|---|---|---|
|15|MOE|0 输出禁用/空闲；1 按 CCxE/CCxNE 开输出；刹车异步清零，软件或 AOE 可恢复|
|14|AOE|0 MOE 仅软件置位；1 刹车不有效时可在下次 UEV 自动置 MOE|
|13|BKP|0 BKIN 低有效；1 高有效；写入一 APB 周期后生效|
|12|BKE|0 关闭 BKIN 与 CSS 刹车输入；1 开启；写入一 APB 周期后生效|
|11|OSSR|MOE=1 时的关闭态：0 禁用未用输出；1 只要一侧通道使能，另一侧可由定时器驱动为无效电平|
|10|OSSI|MOE=0 时的空闲态：0 释放输出使能；1 维持/产生输出使能并按无效→死区→OIS 控制|
|9:8|LOCK|00 不锁；01 锁级 1；10 锁级 2；11 锁级 3|
|7:0|DTG|死区编码，分段换算见[输出级与保护](输出级与保护.md)|

仅TIM1。MOE/OSSI/OSSR与主/N开关的完整组合、DTG分段范围见输出安全文档；LOCK在首次写入BDTR后冻结，配置须预先完整确定。

## TIM1 DMA1请求连线

|请求|DMA1 通道|
|---|---|
|TIM1_CH1|2|
|TIM1_CH2|3|
|TIM1_CH3|6|
|TIM1_CH4 / TIM1_TRIG / TIM1_COM|4|
|TIM1_UP|5|

CH4/TRIG/COM共享DMA1通道4；独立请求使能位不表示独立DMA资源。RM0008 Rev21 p281图50将TIM1_CH2连到DMA1通道3，而p282表78对应格为短横线；本表依据连线图保留这一路，同时明确记录原件差异。

## TIM2～4 DMA1请求连线

|请求|DMA1 通道|
|---|---|
|TIM2_CH1|5|
|TIM2_CH2 / TIM2_CH4|7|
|TIM2_CH3|1|
|TIM2_UP|2|
|TIM3_CH1 / TIM3_TRIG|6|
|TIM3_CH3|2|
|TIM3_CH4 / TIM3_UP|3|
|TIM4_CH1|1|
|TIM4_CH2|4|
|TIM4_CH3|5|

只列实际存在的DMA请求映射，不为表中缺少的通道/事件补造DMA请求。TIM3_CH2及TIM4_CH4没有这里的独立DMA1请求映射；通用DIER中的CCxDE位或HAL接口能接受实例，不等于存在相应物理请求连线。多个事件共享同一物理DMA通道时须解决争用。

## 其余控制语义的归属

- 主/N组合表与MOE=0的合并条件，已在输出安全文档保留，包含GPIO/AFIO及两路均未使用时的脚注。
- DTG四段编码也在输出安全文档统一保留，避免与LL计算宏的整数实现混为一层。
- SR的rc_w0、EGR的写事件副作用、TIM1的COM/Break与TIM2～4的保留位仍须结合完整寄存器定义；本表不代替那些段落。
- MMS=001的原文OR表述与门控模式CEN且TRGI有效的条件存在措辞差异；保留差异，不据该句承诺绕过CEN。
- TIM2～4的OC1PE原文附注涉及不存在的BDTR.LOCK，CCR2～4描述亦有CCMR编号笔误；实现以实际CCMR1/2布局及芯片实例能力为边界。
