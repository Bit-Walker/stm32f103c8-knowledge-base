# TIM 输入滤波与频率测量的数值条件

器件字段和限制引用 RM0008 Rev21、DS5319 Rev20 与 ES096 Rev15。本文以 TIM2 为频率计示例，说明输入滤波、捕获换算、16 位量程及 DMA 配置条件。

先确认[计数时基](计数时基与更新.md)和[输入捕获通路](输入捕获与滤波.md)，具体字段可查[硬件参数表](硬件参数表.md)。AN4776 的历史示例及尚未完成的原文复核，统一说明于第 6 节。

## 1 六次一致采样的滤波例子

ETR 输入使用 `SMCR.ETF`；TI 输入使用 `CCMR.ICxF`。滤波档位同时决定采样频率 $`f_{\mathrm{S}}`$ 和连续一致样本数 $`N`$ 。

本例采用 `ETF=0100`，采样频率为 $`f_{\mathrm{S}}=f_{\mathrm{DTS}}/2`$ ，因此还需通过 `CKD` 确定 $`f_{\mathrm{DTS}}`$ 。具体参数如下：

| 参数 | 设置或结果 |
|---|---|
| 定时器内核时钟 $`f_{\mathrm{CK\_INT}}`$ | $`1\,\mathrm{MHz}`$ |
| `CKD` | `01`，得到 $`f_{\mathrm{DTS}}=500\,\mathrm{kHz}`$ |
| `ETF` | `0100` |
| 滤波采样频率 | $`f_{\mathrm{S}}=f_{\mathrm{DTS}}/2=250\,\mathrm{kHz}`$ |
| 连续一致样本数 | $`N=6`$ |

采样间隔及六个采样间隔的总时长为：

```math
T_{\mathrm{S}}=\frac{1}{f_{\mathrm{S}}}=4\,\mathrm{\mu s},
\qquad N T_{\mathrm{S}}=24\,\mathrm{\mu s}
```

其中， $`T_{\mathrm{S}}`$ 是采样间隔，单位为秒； $`f_{\mathrm{S}}`$ 是采样频率， $`f_{\mathrm{CK\_INT}}`$ 是定时器内核频率， $`f_{\mathrm{DTS}}`$ 是 CKD 分频后的滤波／死区时钟频率，单位均为赫兹； $`N`$ 是连续一致样本数，为无量纲整数。

**不能把 $`24\,\mathrm{\mu s}`$ 直接当作与输入相位无关的通过或拒绝阈值。** 在理想离散采样模型中， $`N`$ 个采样点只跨越 $`N-1`$ 个采样间隔。边沿发生后何时遇到第一个采样点，会改变收集到第 $`N`$ 个样本所需的时间。因此，仅凭 $`N/f_{\mathrm{S}}`$ ，不能断言所有短于 $`24\,\mathrm{\mu s}`$ 的脉冲都会被拒绝。

实际配置还需检查：

- 输入同步和电气路径对最短有效高、低电平宽度的要求
- 滤波造成的边沿延迟，以及它对脉宽测量的影响
- 增大 $`N`$ 或降低 $`f_{\mathrm{S}}`$ 后，目标输入速率是否仍可通过

来源：[RM0008 Rev21 ETF 字段，p342、p407](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=407)、[ICxF 字段，p351](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=351)。采样相位说明由连续样本定义推导，不是实测的器件延迟界限。

## 2 外部计数与同步时钟约束

ETR 或 TI 作为计数源时，定时器的内部逻辑仍需工作，必须使能相应的 RCC 外设时钟。

| 路径 | 必须满足的条件 |
|---|---|
| ETR 预分频 | `ETPS` 位于 ETR 同步、滤波之前，可选除数为 1、2、4、8 |
| ETR 同步输入 | 预分频后的频率满足 $`f_{\mathrm{ETRP}}\le f_{\mathrm{TIM}}/4`$ |
| TI 输入 | 满足 DS5319 表 40、引脚高低电平宽度及所选滤波档位的条件 |
| 捕获预分频 | `ICxPSC` 只作用于捕获支路，不为 `TIxFPx` 触发支路分频 |
| 计数器预分频 | 选定计数源后，还需按 `PSC+1` 计算最终计数频率 |

这里， $`f_{\mathrm{TIM}}`$ 是定时器内核频率， $`f_{\mathrm{ETRP}}`$ 是 ETR 经 `ETPS` 分频后的频率，单位均为赫兹。

例如，`ETPS=10` 表示四分频；若 `PSC` 非零，还要继续除以 `PSC+1`。计算时应分清外部输入频率、定时器内部逻辑时钟、滤波采样频率和计数器频率。

来源：[RM0008 Rev21 时钟路径，pp308–311](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=308)、[SMCR ETPS/ETF 字段，p342](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=342)、[DS5319 表 40，p67](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf#page=67)。

## 3 连续捕获的模差与频率

### 使用公式前的条件

以下公式用于同一极性边沿的连续捕获，要求：

1. 计数器连续向上计数，`ARR` 和计数频率保持不变。
2. 测量区间没有复位、门控、停钟或计数停止，也没有漏捕获。
3. 两笔样本来自同一次连续启用的捕获段，期间没有改变 `ICxPSC`。
4. 实际两次捕获间隔严格小于计数器的一整圈时间，且取模后的计数差大于零。

`CCxE=0` 会复位捕获预分频器。跨越通道停用或预分频重配边界的两笔样本，不能直接沿用同一个捕获分频系数。第一笔样本用于建立时间戳基准；从开始计数到第一笔样本的时间，不能自动视为完整的若干个输入周期。

### 已知计数时钟，求输入频率

令 $`C_1`$ 、 $`C_2`$ 分别为先后两笔捕获值，计数模数为 $`M=\mathrm{ARR}+1`$ 。取模后的计数差为：

```math
\Delta C=(C_2-C_1)\bmod M
```

$`C_1`$ 、 $`C_2`$ 、 $`\Delta C`$ 和 $`M`$ 均为无量纲整数。输入周期与频率分别为：

```math
T_{\mathrm{input}}\approx\frac{\Delta C}{K_{\mathrm{IC}}f_{\mathrm{CNT}}},
\qquad
f_{\mathrm{input}}\approx\frac{K_{\mathrm{IC}}f_{\mathrm{CNT}}}{\Delta C}
```

- $`K_{\mathrm{IC}}`$ 为相邻两次有效捕获跨越的输入周期数；在每周期只有一个所选同极性边沿的条件下，`ICxPSC` 对应 1、2、4、8
- $`f_{\mathrm{CNT}}`$ 为经过 `PSC` 后的计数频率，单位为赫兹
- $`T_{\mathrm{input}}`$ 为输入周期，单位为秒； $`f_{\mathrm{input}}`$ 为输入频率，单位为赫兹

近似号包含整数计数量化及输入路径时序误差。模差法要求：

```math
\Delta C\gt 0,\qquad \Delta t\lt \frac{M}{f_{\mathrm{CNT}}}
```

其中， $`\Delta t`$ 为两次捕获之间的实际时间，单位为秒。

**“最多越过一次零点”不足以保证模差正确。** 间隔恰好一整圈时，模差为零；间隔大于一整圈时，模差会丢失整圈数。扩大测量范围可提高 `PSC`，或建立可靠的回绕计数和捕获边界配对。仅有两个 16 位捕获值，无法恢复未知的整圈数。

### 已知输入参考，反求计数时钟

当输入本身是已知频率的参考信号，且上述捕获条件成立时：

```math
f_{\mathrm{CNT,actual}}\approx\frac{\Delta C f_{\mathrm{REF}}}{K_{\mathrm{IC}}}
```

其中， $`f_{\mathrm{REF}}`$ 是已知输入参考频率， $`f_{\mathrm{CNT,actual}}`$ 是反求得到的实际计数频率，单位均为赫兹。

若要恢复 `PSC` 之前的时钟频率，还需乘以 `PSC+1`；若计数源来自 ETR，且输入被完整计数，恢复 ETR 引脚频率还需乘以 `ETPS` 的除数。

### 频率误差的 ppm 表示

有符号偏差及其幅值为：

```math
e_{\mathrm{ppm}}=10^6\frac{f_{\mathrm{meas}}-f_{\mathrm{nom}}}{f_{\mathrm{nom}}},
\qquad
|e_{\mathrm{ppm}}|=10^6\frac{|f_{\mathrm{meas}}-f_{\mathrm{nom}}|}{f_{\mathrm{nom}}}
```

其中， $`f_{\mathrm{meas}}`$ 是测得频率， $`f_{\mathrm{nom}}`$ 是大于零的标称频率，单位均为赫兹。 $`e_{\mathrm{ppm}}`$ 是以百万分比表示的无量纲偏差，正值表示偏高，负值表示偏低。

计数与捕获依据：[RM0008 Rev21 §§15.3.1–5，pp368–384](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=368)。公式由计数模数和捕获预分频关系推导；捕获完整性还受 [ES096 捕获标志竞争限制](https://www.st.com/resource/en/errata_sheet/es096-stm32f101x8b-stm32f102x8b-and-stm32f103x8b-mediumdensity-device-limitations-stmicroelectronics.pdf#page=15)影响。

## 4 频率计的资源与量程

### 引脚与计数宽度

TIM2 为 16 位定时器。未重映射时，可使用：

- `PA0`：`TIM2_ETR/CH1`
- `PA1`：`TIM2_CH2`

使用 CH2 捕获待测输入，可避开 ETR 与 CH1 共用 PA0 的问题。接线前仍需核对输入电压、封装引脚和 AFIO 重映射状态。

### 数值复算

下表以不同的计数基准分别复算。ETR 计数例子均假定 `PSC=0`；其他 `PSC` 设置还需再除以 `PSC+1`。

| 条件 | 复算结果 | 使用边界 |
|---|---|---|
| $`f_{\mathrm{CNT}}=8\,\mathrm{MHz}`$ ，`ARR=65535` | 一整圈为 $`8.192\,\mathrm{ms}`$ | $`f_{\mathrm{CNT}}`$ 已包含 `PSC` 的作用 |
| $`K_{\mathrm{IC}}=1`$ ，不展开回绕 | 输入频率须严格大于 $`122.0703125\,\mathrm{Hz}`$ | 等于此值时恰好一整圈，模差为零 |
| $`1\,\mathrm{kHz}`$ 输入，内部 $`8\,\mathrm{MHz}`$ 计数 | 约 8000 计数/周期 | 分别核对计数基准误差和量化误差 |
| $`1\,\mathrm{kHz}`$ 输入，ETR 为 $`8\,\mathrm{MHz}`$ ，`ETPS` 四分频 | 约 2000 计数/周期 | $`f_{\mathrm{ETRP}}=2\,\mathrm{MHz}`$ ；当 $`f_{\mathrm{TIM}}=8\,\mathrm{MHz}`$ 时恰在四分之一频率边界 |
| $`1\,\mathrm{kHz}`$ 输入，ETR 为 $`10\,\mathrm{MHz}`$ ，`ETPS` 八分频 | 约 1250 计数/周期 | $`f_{\mathrm{ETRP}}=1.25\,\mathrm{MHz}`$ 满足 $`8\,\mathrm{MHz}`$ 内核的上述频率不等式；仍需核对电气及滤波条件 |

第一行可直接核算为 $`8\,\mathrm{MHz}\times8.192\,\mathrm{ms}=65536`$ 。外部参考源更准确，并不消除较粗计数刻度带来的量化误差。

计算 `PSC` 时，应使用实际进入预分频器的计数源频率。只有这个频率恰好等于 `SystemCoreClock` 时，才能直接代入该变量；使用 ETR 时，还需先计入 `ETPS`。

引脚与实例依据：[DS5319 Rev20 表 5](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf#page=28)、[RM0008 TIM2～4 资源与时钟选择](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=365)。

## 5 TIM2_CH2采样与DMA边界

### 采样目标

TIM2_CH2 的 DMA 请求固定映射到 DMA1 通道 7。采集 1000 次捕获时，本例采用：

| 项目 | 配置 |
|---|---|
| 缓冲区 | 1000 个 `uint16_t` 元素，共 2000 字节 |
| 外设地址 | 固定为 `CCR2` 地址 |
| 内存地址 | 缓冲区首地址，逐项递增 |
| 传输方向 | 外设到内存 |
| 数据宽度 | 外设和内存均为 16 位 |
| DMA 模式 | 正常模式 |
| 初始传输数量 | `CNDTR=1000` |

### 初始化顺序

以下步骤是一组配置契约。执行前应确认时钟、引脚、缓冲区及资源归属。

1. **隔离正在使用的资源。**  
   停止计数，关闭 `CC2E`、`CC2DE` 和 DMA 通道。协调同一定时器的其他用户、共享 DMA 请求，以及可能接收 `UG/TRGO` 事件的下游外设。

2. **恢复连续向上计数。**  
   退出编码器、门控、复位等从模式；先选择 `CMS=00`，再设置 `DIR=0`。设置 `OPM=0`，并设置 `UDIS=0`，允许后续 `UG` 装载 `PSC/ARR`。
   - 内部独立计数：`SMS=000`、`ECE=0`
   - 本例 ETR 外部时钟模式 2：`SMS=000`、`ECE=1`，同时配置 `ETPS`、`ETF` 和输入极性

3. **装载时基并处理初始化标志。**  
   在请求尚未开放时，用 `UG` 装载时基，随后处理初始化产生的状态标志。

4. **配置捕获输入。**  
   保持 `CC2E=0`，配置 `CC2S=01`、上升沿和 `IC2PSC=DIV1`，并按输入条件设置滤波。

5. **选择捕获事件产生 DMA 请求。**  
   显式设置 `CR2.CCDS=0`。`CCDS` 是整个定时器实例共享的位，修改前须协调其他通道。  
   `CCDS=1` 选择更新事件；此时即使 DMA 地址仍指向 `CCR2`，搬运次数也不能代表捕获次数。

6. **配置 DMA 通道 7。**  
   设置 `CPAR=CCR2` 地址、`CMAR=缓冲区`、`CNDTR=1000`、`MINC=1`、`DIR=0`，并使外设及内存宽度与缓冲区一致。清除旧 DMA 状态。

7. **按接收端先就绪的顺序启动。**  
   先准备 DMA 接收，再开放 `CC2DE`、`CC2E` 和计数。为无输入、DMA 错误、超时及资源冲突提供处理路径。

### 完成判定

DMA 的 TC 标志只证明该配置完成了相应次数的搬运。它本身不能证明没有漏捕获，也不能替代缓冲区状态和数据配对检查。

结束采样时，应停止外设请求、捕获和 DMA，再确认完成状态、错误状态及数据配对。`CC2OF` 的表现受 ES096 限制，不能作为唯一的样本完整性证据。

不要假定输入捕获初始化会自动恢复上次用途留下的 `OPM`、`UDIS` 或 `CCDS`。固定 HAL 版本相关路径的作用范围，见[捕获 DMA 请求选择](HAL生命周期与DMA.md#捕获dma的请求时机与旧配置)。

来源：[RM0008 Rev21 CR1/CR2 字段，pp404–406](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=404)、[DMA1 请求映射表 78](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=282)、[TIM2 DIER 与 CCR 相关字段](https://www.st.com/resource/en/reference_manual/cd00171190.pdf#page=409)、[HAL 停止与状态边界](HAL生命周期与DMA.md)。本节未提供已编译或实测的完整工程。

## 6 原测量图的证据边界

AN4776 的完整原 PDF 尚未完成全文复核。本文保留既有笔记中的应用目标和数值例子；原平台、原图和跨系列说明的适用范围如下。

### 原平台与量程边界

原笔记记录的平台为 NUCLEO-F302R8，其中 $`8\,\mathrm{MHz}`$ 与 $`10\,\mathrm{MHz}`$ 参考属于不同示例，不能拼成同一组配置。

原例的两项数值仅用于说明移植边界，不作为本页的配置选项：

- 对 $`1\,\mathrm{kHz}`$ 输入， $`10\,\mathrm{MHz}`$ ETR 经四分频、`PSC=0` 时，算术结果为约 2500 计数/周期。但在 $`8\,\mathrm{MHz}`$ 定时器内核下，分频后的 $`2.5\,\mathrm{MHz}`$ 超过 $`f_{\mathrm{TIM}}/4=2\,\mathrm{MHz}`$ ，该配置不可用。
- 原笔记中 32 位示例约 $`0.002\,\mathrm{Hz}`$ 的测量下限，不能用于这里的 16 位计数器。

### 原测量分布

原笔记保留了 1000 样本的 HSI 与外部基准 ppm 分布，以及接口和系统框图。它们不能作为本器件的实测性能保证。

部分裁剪图缺少横轴、纵轴或存储缓冲区标签，因此不据此读取精确分箱、极值或“零误差”结论。评价实际测量结果时，应分别考虑：

- 制造偏差及温度、电压漂移
- 参考源误差和输入抖动
- 同步、计数量化及显示精度

### 原滤波图的局部标注

原笔记中的图 4 在下降阶段连续将 “Filter counter” 标为 0，但输出仍延后下降。该局部标注不足以证明低电平沿绕过滤波，不能据此删去下降沿的滤波条件。

### 跨系列同步模型

原笔记使用两级同步器示意异步输入同步，并记录了约 2～3 个内核时钟的模型，以及：

```math
f_{\mathrm{TIM}}\ge 3f_{\mathrm{IN}}
```

其中， $`f_{\mathrm{IN}}`$ 为异步输入频率， $`f_{\mathrm{TIM}}`$ 为定时器内核频率，单位均为赫兹。这些内容属于跨系列说明，不能替代第 2 节的器件约束，也不能据此声称亚稳态概率为零。
